# PERFORM AI Visual QA

The public landing page and phone-sized private rehearsal app were checked at **390 × 844**. The layout keeps the Saint Bernard icon visible, positions the PERFORM AI title beneath the top browser region, preserves the minimal public gateway copy, and does not expose private script text, history, or fabricated scores.

The global colour controls now have exactly four user-facing modes. **Blue + Green Rain** is the default; it combines a blue/dark-blue background, light-green text, and animated green falling code. The three non-default modes are **Black + Gold**, **Black + Light Blue**, and **White + Black / Blue**. The app’s shared `AppScreen` shell provides all four choices on every end-user app screen. The landing header presents the same four choices.

The browser capture verifies the 390 × 844 layout and the visibility of the logo. Native iPhone and iPad safe-area behaviour remains a physical-device check because the actual camera/notch inset is supplied by `SafeAreaView` at runtime.
